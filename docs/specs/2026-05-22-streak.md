## Goal

Cho phép user xem lại lịch sử ảnh đã post (chính mình) theo dạng calendar (tháng) + chi tiết từng ngày (carousel swipe). **Read-only** — không tạo post từ đây. Tính streak liên tiếp + tổng moments client-side cộng denormalized từ Profile.

---

## User stories

- Là user, tôi muốn xem các ngày tôi đã post ảnh trong tháng qua dạng calendar có thumbnail.
- Là user, tôi muốn tap vào 1 ngày để xem ảnh ngày đó (carousel swipe trong tháng).
- Là user, tôi muốn biết tổng số khoảnh khắc và số ngày chuỗi liên tiếp hiện tại.
- Là user, tôi muốn chia sẻ hoặc xoá một ảnh từ Streak.
- Là user (chưa post lần nào), tôi muốn được khuyến khích đăng khoảnh khắc đầu tiên.

## Data model

Streak **KHÔNG** có Firestore collection riêng — read-only từ `/posts` và `/users`.

### Fields cần đọc

`/posts/{postId}` — qua StreakRepository:
```
postId, authorId, coverImageUrl (getter), caption, createdAt
imageUrl OR backImageUrl/frontImageUrl/isDualCamera (qua coverImageUrl getter)
spaceId  // filter spaceId == null để loại bỏ Space posts khỏi calendar cá nhân
```

`/users/{uid}` — qua existing `currentUserProfileProvider`:
```
postCount  // denormalized — totalMoments source of truth
```

### Timezone contract

Mọi so sánh ngày convert về **device local timezone** trước:
```dart
final localDate = post.createdAt.toLocal();
final dayKey = DateTime(localDate.year, localDate.month, localDate.day);
```

Không dùng UTC trực tiếp. Tests phải cover post 23:00 UTC + device UTC+7 → tính ngày local (24h sau ở UTC).

## Repository interface

```dart
abstract class StreakRepository {
  /// Watch posts của user trong [month] (local timezone), loại bỏ Space posts.
  ///
  /// Query: WHERE authorId == uid
  ///        AND spaceId == null
  ///        AND createdAt >= startOfMonthLocal
  ///        AND createdAt <  startOfNextMonthLocal
  ///        ORDER BY createdAt ASC
  ///
  /// Throws StreakLoadError on Firestore failure (mapped from FirebaseException).
  Stream<List<Post>> watchUserMonth(String uid, DateTime month);

  /// Read once all dates user has posted (for streak calculation).
  ///
  /// Returns DateTime list (already converted to local timezone, deduped per day).
  /// Cached trong controller — chỉ refetch khi mở màn hoặc deletePost trigger refresh.
  ///
  /// Query: WHERE authorId == uid
  ///        AND spaceId == null
  ///        ORDER BY createdAt DESC
  ///        (select createdAt only nếu SDK support — giảm payload)
  Future<List<DateTime>> getUserAllDates(String uid);
}
```

## Controller pattern

```dart
@freezed
class StreakState with _$StreakState {
  const factory StreakState({
    @Default([]) List<Post> monthPosts,
    @Default([]) List<DateTime> allPostDates,
    DateTime? viewingMonth,            // null = chưa init
    @Default(0) int currentStreak,
    @Default(false) bool isLoading,
    String? errorMessage,              // pattern AUTH #8
  }) = _StreakState;
}

@riverpod
class StreakController extends _$StreakController {
  StreamSubscription<List<Post>>? _monthSub;

  @override
  StreakState build() {
    ref.onDispose(() => _monthSub?.cancel());
    return const StreakState();
  }

  Future<void> init() async { /* load tháng hiện tại + allPostDates */ }
  Future<void> swipePrev() async { /* viewingMonth - 1 */ }
  Future<void> swipeNext() async { /* viewingMonth + 1, cap tại tháng hiện tại */ }
  void clearError() { /* pattern AUTH #4 */ }

  StreakState _afterFailure(Object e, {String fallback = 'Không thể tải Kỷ niệm'}) {
    final err = AppError.fromUnknown(e, fallback: fallback);
    return state.copyWith(isLoading: false, errorMessage: err.message);
  }
}

/// Pure function — testable không cần Riverpod.
int calculateStreak(List<DateTime> postDatesLocal, DateTime nowLocal) {
  final daySet = postDatesLocal
      .map((d) => DateTime(d.year, d.month, d.day))
      .toSet();
  int streak = 0;
  var day = DateTime(nowLocal.year, nowLocal.month, nowLocal.day);
  while (daySet.contains(day)) {
    streak++;
    day = day.subtract(const Duration(days: 1));
  }
  return streak;
}

/// `totalMoments` lấy từ `currentUserProfileProvider`, không lưu trong StreakState.
/// StreakStatsPill ref.watch cả `streakControllerProvider.select((s) => s.currentStreak)`
/// và `currentUserProfileProvider.select((p) => p?.postCount ?? 0)`.
```

## Security

KHÔNG có Firestore rule mới — Streak chỉ read + delete, dùng rules đã deploy:

```javascript
// /posts/{postId} — đã có từ Feed
match /posts/{postId} {
  allow read:   if isAuthed() && (
    request.auth.uid == resource.data.authorId ||
    exists(/databases/$(database)/documents/users/$(request.auth.uid)/feed/$(postId))
  );
  allow delete: if isAuthed() && request.auth.uid == resource.data.authorId;
  allow update: if false;
}
```

Client check `isAuthor = (post.authorId == currentUid)` để gate UI nút Xoá. Server vẫn enforce qua rule.

## Risks

- **Performance calendar thumbnail:** mỗi ô = 1 CachedNetworkImage. Mitigation: dùng URL gốc (Firebase Storage tự generate thumbnail signed URL nếu config), hoặc bỏ qua khi >40 post/tháng.
- **Move shared widget:** PhotoDetailScreen + SharePhotoSheet đang ở Profile → cần update import trong ProfileScreen. Risk: break Profile widget tests. Mitigation: chạy `flutter test test/features/profile/` sau move.
- **Streak calculation drift timezone:** mitigation = pure fn + test edge case 23:00 UTC.
- **Profile postCount drift:** nếu CF `onPostCreated/onPostDeleted` fail → postCount stale. Mitigation: chấp nhận eventual consistency; nếu drift > 1, recompute server-side (out-of-scope spec này).
- **CaptionType.streak unresolved:** Feed đang ship mock cho caption type 7. Streak không expose API → caption type 7 vĩnh viễn mock cho đến khi OQ4 resolve. Acceptable (caption optional, user ít dùng).
