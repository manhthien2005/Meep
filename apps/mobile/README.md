# Meep — Flutter app

Mobile client for Meep. **MVP target: Android only.** iOS deferred post-MVP per `docs/adr/0002-android-first-defer-ios.md` — codebase stays cross-platform-ready.

## First-run setup

```bash
# 1. Install dependencies
flutter pub get

# 2. Wire Firebase (interactive — run once per environment)
#    Requires: dart pub global activate flutterfire_cli
flutterfire configure --project=<your-firebase-project-id>
#    → generates lib/firebase_options.dart and updates ios/android config.

# 3. Run code generation (Riverpod / freezed / json_serializable)
dart run build_runner build --delete-conflicting-outputs

# 4. Run the app
flutter run
```

## Project layout

```
lib/
├── core/                     # cross-feature plumbing
│   ├── theme/                # AppTheme (Material 3, light + dark)
│   ├── error/                # AppError sealed hierarchy
│   └── router/               # go_router config (TODO)
└── features/                 # 1 folder per feature
    └── auth/
        ├── data/             # AuthRepository (interface + Firebase impl)
        ├── application/      # Controllers (Riverpod)
        └── presentation/     # Widgets / pages

test/                         # mirrors lib/ structure
integration_test/             # E2E tests via integration_test package
```

See `.windsurf/rules/21-flutter-rules.md` for full layering / state management / testing conventions.

## Tests

## Build

```bash
flutter build apk --release                 # Android APK (target chính)
flutter build appbundle --release           # Play Store AAB
# flutter build ipa --release               # iOS — deferred per ADR-0002, không chạy trong MVP
```

## Notes

- `lib/firebase_options.dart` is generated by `flutterfire configure` — gitignored, do NOT commit.
- `*.g.dart`, `*.freezed.dart`, `*.mocks.dart` are also gitignored (regenerate via `build_runner`).
- For widget development without Firebase, the auth repository must be overridden with a fake (see `test/features/auth/presentation/login_page_test.dart`).
